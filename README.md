Uma landing page moderna para SaaS, desenvolvida com **Next.js 15**, **React 19**, **TypeScript** e **Tailwind CSS**.

FlowSync é um projeto fictício de plataforma de gerenciamento de projetos, desenvolvido para demonstrar uma arquitetura front-end de qualidade profissional, design responsivo, animações suaves e padrões modernos de interface inspirados nas principais empresas de SaaS da atualidade.

---

## Prévia

> Landing page responsiva para SaaS, com interface limpa, componentes reutilizáveis e desempenho otimizado.

**Demonstração online:**

https://flowsync-livid.vercel.app/

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/wwilliamsantana/flowsync.git
```

Acesse a pasta do projeto:

```bash
cd flowsync
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse no navegador:

```text
http://localhost:3000
```

---

## Build de produção

Gere a versão de produção:

```bash
npm run build
```

Inicie o servidor de produção:

```bash
npm start
```

## Objetivos do projeto

O objetivo deste projeto foi simular o desenvolvimento e a entrega de uma landing page profissional para uma startup SaaS, seguindo boas práticas de desenvolvimento voltadas para aplicações de qualidade profissional.

Os principais pontos trabalhados foram:

- Código limpo.
- Reutilização de componentes.
- Design responsivo.
- Acessibilidade.
- SEO.
- Desempenho.
- Arquitetura de fácil manutenção.
